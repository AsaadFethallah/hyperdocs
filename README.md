# Asaad FETHALLAH Hyperdocs

This is a separate, static personal documentation experience for Asaad FETHALLAH. It lives beside the React portfolio so it can evolve as a personal dossier, profile link, or documentation microsite.

## Open it locally

From the `Portfolio` folder, run:

```bash
python -m http.server 8000
```

Then open:

```text
http://127.0.0.1:8000/hyperdocs/
```

The CV button points to the current PDF at `asaad-fethallah-portfolio/public/AsaadFethallah_CV_PFE_EN.pdf`.
